# RustSBI 核心库

本章将详细介绍 RustSBI 核心库的架构设计与功能模块。

> RustSBI 核心库通常用于开发 SBI 生态的系统软件。若需要寻找 RustSBI 提供的 SBI 固件以供下载、安装到真实硬件主板或模拟器，请参阅第三章 RustSBI Prototyper 项目。

RustSBI 核心库采用分层设计，将核心功能与机器态实现解耦，通过多个模块化的 Rust 包（crate）为 RISC-V SBI 生态提供支持。其模块化架构适用于内核开发、安全固件设计、虚拟化方案及模拟器等不同场景，并不仅限于机器态 RISC-V 固件。按功能可分为以下四类：

1. [`rustsbi` SBI 服务抽象层](02_libraries/01_rustsbi.md)

    该包通过特型（trait）机制抽象 SBI 扩展功能，并提供派生宏支持。开发者在构建裸机固件时，可为平台结构体实现相应的 SBI 扩展 trait，再通过 `#[derive(RustSBI)]` 宏自动生成 SBI 调用的分发逻辑，降低 SBI 底层开发的复杂度。针对虚拟化场景，支持为虚拟机单独实现扩展或通过 `Forward` 机制转发 SBI 调用至宿主机。对于运行于非 RISC-V 宿主平台的模拟器，可利用宿主平台特性跨架构地提供 SBI 运行环境。

2. [内核态最小运行环境](02_libraries/02_runtime.md)

    为操作系统内核、虚拟机监控程序等特权态软件提供 SBI 及相关扩展的 Rust 调用接口，将底层常量和内联汇编封装为类型安全的函数，便于开发者调用运行环境提供的服务。主要包括：

    - `sbi-rt`：封装 RISC-V SBI 标准接口的调用。
    - `riscv-cove-rt`：封装机密虚拟机扩展（CoVE）的宿主接口调用。

3. [规范常量与数据类型](02_libraries/03_specifications.md)

    提供 SBI 及相关规范的常量、数据结构与类型定义，供服务实现和调用方共同使用；部分库还提供相应的底层访问接口。主要包括：

    - `sbi-spec`：定义 SBI 扩展编号（EID）、函数编号（FID）及标准数据类型。
    - `riscv-cove`：定义机密虚拟机扩展（CoVE）的接口常量与数据结构。
    - `riscv-aia`：提供高级中断架构（AIA）的寄存器与中断类型定义，以及底层访问接口。
    - `penglai`：定义蓬莱 PMP 扩展的 SBI 接口常量与数据结构。
    - `rpmi`：定义 RISC-V 平台管理接口（RPMI）的协议常量与数据类型。

4. [自动化测试框架](02_libraries/04_testing.md)

    为裸机环境提供 SBI 一致性测试用例与测试流程，支持快速构建 SBI 测试内核，自动执行测试用例并输出测试结果，减少测试套件的重复开发工作。目前主要包括：

    - `sbi-testing`：提供用于验证 SBI 执行环境功能的测试用例及自动化测试支持。

需要特别说明的是，RustSBI 核心库聚焦于跨平台抽象层和开发工具链，不包含具体硬件平台的机器态实现。如需获取可直接部署的 RISC-V SBI 固件，请参阅第三章提供的硬件适配方案。
